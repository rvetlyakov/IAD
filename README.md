# IAD — исследование генетического алгоритма для задачи о назначениях

Генетический алгоритм минимизирует суммарную стоимость назначения работников
на позиции. Хромосома — перестановка индексов столбцов матрицы стоимости.
Каждый работник получает одну позицию, каждая позиция используется один раз.

## Алгоритм

- **Начальная популяция:** случайные перестановки.
- **Приспособленность:** `1 / стоимость` (для положительных стоимостей).
- **Мутация:** инверсия случайного непрерывного фрагмента длиной от 2 до
  `ceil(n * mutation_percent / 100)` (с границей минимум 2 и максимум n).
- **Потомки:** мутанты добавляются к исходной популяции с вероятностью
  `mutation_probability`. Скрещивания нет.
- **Отбор:** remainder stochastic sampling (целая часть ожидаемого числа
  копий плюс отбор по дробным остаткам) с сохранением `elitist_percent`
  лучших особей. После отбора размер популяции всегда `population_size`.
- **Остановка:** максимум `max_iterations` поколений либо `plateau_limit`
  последовательных относительных изменений средней приспособленности,
  не превышающих `plateau_diff`.
- **Эталон:** точное решение задачи о назначениях через метод
  `scipy.optimize.linear_sum_assignment` (не полный перебор).
- Аргумент `tournament_size` сохранён для совместимости со старыми вызовами;
  он НЕ используется при RSS и не является исследуемым гиперпараметром.

## Исследование гиперпараметров на 21 октября

Задание: исследовать влияние каждого гиперпараметра на качество ГА для
трёх классов задач разной размерности, изменяя ровно один параметр за раз.

Условные классы исследуемых матриц:

| Класс | Размеры |
|---|---|
| Малая | 3×3, 5×5 |
| Средняя | 8×8, 12×12 |
| Большая | 16×16, 24×24 |

Матрицы содержат случайные положительные целые значения от 1 до 100.
На каждой размерности генерируется шесть матриц, и на каждой выполняется
два независимых запуска с фиксированными seed для каждого значения
параметра. **Один и тот же набор матриц и seed** используется во всех
сравниваемых конфигурациях. Базовая конфигурация записана в
`lab1/experiments.py`; изучаются семь изменяемых параметров:

| Параметр | Исследуемые значения |
|---|---|
| `population_size` | 50, 100, 200, 300 |
| `mutation_probability` | 0.2, 0.5, 0.7, 1.0 |
| `mutation_percent` | 15, 30, 45, 60 |
| `elitist_percent` | 0, 0.1, 0.2, 0.3 |
| `plateau_limit` | 3, 5, 10, 20 |
| `plateau_diff` | 0, 1e-6, 1e-4, 1e-3 |
| `max_iterations` | 50, 100, 200, 400 |

Относительное отклонение вычисляется как
`(GA_cost - exact_cost) / exact_cost`. Например, значение 1.4 означает
отклонение 140%, **а не** «не более 40%». Отчёт включает среднее и
максимальное отклонение, стандартное отклонение, долю точных решений,
число поколений и среднее время выполнения. Время замеряет **весь**
вызов `run_ga`, включая вызов SciPy для вычисления эталона.

После запуска получаются:

- `results/raw_results.csv`: все отдельные испытания;
- `results/summary.csv`: агрегаты по размерности и классу;
- `results/metadata.json`: параметры исследования;
- `results/plots/*.png`: отклонение, доля точных решений и время
  для каждого изменяемого параметра;
- `lab1/testing.ipynb`: воспроизводимое представление результатов.

**Ограничения исследования:** это эвристический стохастический метод;
результаты зависят от набора тестовых задач и seed. Малая разница средних
значений не доказывает отсутствие влияния без дополнительной
статистической проверки. Классы размерности здесь условны.
