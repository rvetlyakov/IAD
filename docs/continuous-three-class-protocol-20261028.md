# Непрерывные размерности и проверяемый подбор ГА — 28.10.2026

## Классификация и графики

Три непересекающихся группы: малые 2 ≤ n < 100; средние
100 ≤ n < 500; большие 500 ≤ n ≤ 2000. Поэтому диапазон 550–950
входит в большие и не выделяется отдельно. 1×1 тривиальна; 0×0
в исследования не включается.

Графическая ось X непрерывная кусочно-линейная: малый, средний
и большой диапазоны получают равную визуальную ширину. Участки
соединяются без пустого промежутка в n=100 и n=500.
Это нелинейный масштаб по n, не равные интервалы между точками.
Каждая вершина кривой — подлинное измерение. PCHIP, скользящее
среднее, синтетические промежуточные значения НЕ используются.
Настоящие скачки ошибки на графике сохраняются.

## Методика нового подбора

1. TRAIN: при фиксированных остальных настройках подобрать число
поколений G, затем отдельно число кандидатов локального поиска K.
2. Последовательно варьировать каждый из остальных активных
гиперпараметров на одинаковых матрицах и seed: мутация, RSS,
ранговая степень, элитизм, локальный поиск, 3-cycle, популяция
и т.д. Отдельно настроить 1/2/4/8 островов и миграцию.
3. Проверить перенос значений параметров между размерностями.
Переносить значение с больших на малые/средние лишь при
фактическом снижении ошибки на TRAIN матрицах целевого класса.
Число особей и поколений целевого класса в такой проверке
не меняются.
4. Зафиксировать настройки. На НЕ использованных при обучении
SURVEY матрицах (два seed на n) исследовать по одному фактору
и вычислить чувствительность: размах средней ошибки между
исследованными значениями в процентных пунктах.
5. На новых HOLDOUT матрицах сравнить исходную, tuned single и
tuned islands. В паре tuned single/islands одинаковы общая
популяция N, количество поколений G, расписание и число вызовов
локального улучшения. Время включает затраты на multiprocessing.

Команды полного запуска:

    python -m unittest discover -s tests -v
    python lab1/staged_tuning.py --class-name all --stage train
    python lab1/staged_tuning.py --class-name all --stage refine
    python lab1/staged_tuning.py --class-name all --stage transfer
    python lab1/staged_tuning.py --class-name all --stage ofat
    python lab1/staged_tuning.py --class-name all --stage holdout
    python lab1/staged_charts.py --root results/staged_tuning_v2

Можно использовать --stage all в одном вызове.

## Ограничения и честность интерпретации

Нахождение лучшего одиночного значения в OFAT не доказывает
оптимальности комбинации таких значений. В историческом наборе
одна матрица и один seed на размер n; близкие результаты
статистически не различимы по нему. Параллельный ГА может
иметь такие же N и G, но другое общее время процессора.
Новый 3-cycle — улучшение исходной схемы, а не исключительно
инверсия + RSS без дополнительных операторов.
Параметры ранней остановки по плато исследуются отдельно,
так как для сравнения островов G фиксируется.

Ни новые замеры, ни отсутствующие графики не должны
подменяться интерполяцией или вымышленными цифрами.
