## Исправленные ошибки кода

1. Метод Employee.fitness(vector) использовал self.vector вместо переданного vector. Исправлен.
2. Нулевая стоимость оптимального назначения вызывала ZeroDivisionError в fitness/rel_gap. Исправлено с документированным бесконечным относительным отклонением для неоптимального результата при оптимуме 0.
3. В одиночном ГА лучший мутант, потерянный при RSS, не сохранялся в итоговой оценке. Теперь учитывается лучшее когда-либо рассмотренное решение.
4. Критерий плато в старом run_ga не включал фитнес исходной популяции и требовал на одно поколение больше по сравнению с другой реализацией. Теперь отсчёт последовательных изменений единообразен.
5. В старом скрипте островной миграции population_size означал **число особей на один остров**, что нарушало условие равного общего числа особей при прямом сравнении. Теперь это **общий** бюджет, делимый с остатком между островами.
6. Средняя приспособленность островной модели считалась как невзвешенное среднее средних разных по размеру популяций. Исправлено: взвешенное среднее по общему числу особей.
7. В точном benchmark exact_cost() не обрабатывал вложенные списки как numpy-массивы. Исправлено.
8. Некорректные параметры mutation_probability, mutation_percent, elitist_percent, n и неквадратные матрицы могли приниматься без ранней валидации. Теперь вызывает ValueError с причиной.
9. В старом experiments.py измерение времени включало SciPy. Теперь оптимум вычисляется один раз на тестовую матрицу **за пределами таймера**, а run_ga умеет принимать reference_cost.
10. В новом исследовании раньше отсутствовал полный снимок настроек каждой строки. В новые измерения добавлен settings_json, позволяющий независимо подтвердить OFAT.

## Научные ограничения (нельзя подменять их «исправлениями»)

- Основной ГА с обратной стоимостью fitness=1/C, случайной инверсией, RSS и элитизмом может иметь ошибку порядка 4000–4500% на n=1000–2000: это недостаточная эффективность данного метода и вычислительного бюджета, а не арифметическая ошибка.
- На больших матрицах fitness случайных назначений близки; при N=120, 100%-й вероятности мутации и 10%-м элитизме большая часть RSS-копий назначается исключительно стохастически.
- Нелинейная шкала symlog сжимает видимые различия 4300–4700%. Интерпретировать маленькие визуальные расстояния как идентичные показатели неверно.
- Исторический однофакторный эксперимент 465 запусков содержит **один запуск на точку**; этого недостаточно для оценки значимости малых разниц. Старые данные считаются историческими и не изменяются после правок кода.
- Последовательный OFAT на одной тренировочной матрице/классе не является доказательством глобального оптимума конфигурации. Лучшие значения — только лучшие из реально проверенных.
- Старый диапазон plateau_diff=(0.005, 0.02, 0.05) давал практическое совпадение результатов и раннюю остановку. Код нового исследования использует (0, 1e-7, 1e-6, 1e-5, 1e-4) и плато проверяется отдельно на одном ГА; полный повторный эксперимент сохраняется в results/plateau_corrected_20261027 **только после фактического завершения**.
- После изменения времени в experiments.py сохранённые старые цифры продолжительности относятся к **старой версии** методики. Переписывать их без запуска нельзя.
- Улучшение качества на n≥1000 требует **отдельного** эксперимента с большими вычислительными бюджетами и/или другими операторами. Мутация, RSS и элитизм не заменены произвольно.

## Проверка

Запустить весь набор:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Для быстрого benchmark:

```bash
python lab1/scale_benchmark.py --mode smoke --workers 2
python lab1/hyperparameter_curves.py --mode smoke --workers 2 --parameters mutation_probability num_islands plateau_diff
```

Для полного воспроизводимого сравнения используется документированная команда из docs/scale-benchmark.md; использовать **результаты GitHub Actions**, а не фиктивные значения. Проверенные данные лежат под results/. Версии должны быть указаны на защите.
