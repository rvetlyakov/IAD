# Масштабное исследование ГА и островной модели

**Новая методика (26.10.2026).** Старые результаты на 3–24 и
results/CONCLUSIONS.md относятся к предыдущей учебной постановке.
Их нельзя выдавать за результаты для матриц от 100 до 2000.

## Классы размерностей

- Малая: 10×10, 30×30, 50×50.
- Средняя: 100×100, 300×300, 500×500.
- Большая: 1000×1000, 1500×1500, 2000×2000.

Размер матрицы — число работников и одновременно число должностей,
а не число особей ГА. Элементы — воспроизводимые случайные целые стоимости
от 1 до 100. Для вычисления сумм используется int32, а не uint8 (у uint8
происходит переполнение). Эталон — точное линейное назначение SciPy.

## Как ищем гиперпараметры

Новая программа: lab1/scale_benchmark.py.

1. Для каждого класса на репрезентативной тренировочной размерности
   (30 / 300 / 1500) выполняется последовательный однофакторный подбор.
   Меняется один параметр, затем лучшее **наблюдённое** значение
   фиксируется и начинается следующий параметр.
2. Общие параметры (сначала для обычного ГА): общий размер популяции,
   вероятность и максимальная длина мутации, элитизм, число поколений.
3. При тех же общих настройках подбираются островные параметры:
   **количество островов** (2, 3, 4), период миграции и доля мигрантов.
   Число островов — полноценный исследуемый гиперпараметр.
4. На **новых, независимых** матрицах (контрольная выборка)
   сравниваются один ГА и многопроцессный островной ГА на пяти точках
   размерности внутри каждого класса. Одни и те же матрицы и суммарное
   число особей используются для обеих моделей.

Подбор последовательный, а не глобальный перебор всех сочетаний.
"Лучшие гиперпараметры" означает **лучшие наблюдавшиеся среди
проверенных вариантов при заданном бюджете**; это не математически
оптимальная конфигурация и не доказательство превосходства алгоритма.
Фактические значения выводятся только после запуска.

## Что значит честное сравнение

Для одного и островного ГА совпадают:
- входная матрица, включая seed;
- исходный набор N случайных хромосом;
- **общее** N: для 80 особей и 4 островов получается по 20 на остров,
  а не 80×4 = 320;
- число поколений, вероятность мутации, инверсия и доля элитизма.

Реальная параллельность: ProcessPoolExecutor выполняет острова в
отдельных процессах, а не последовательно в обычном цикле.
Острова обмениваются лучшими решениями по кольцу. Учтены накладные
расходы запуска процессов, межпроцессной передачи и миграции.
Параметр --workers задаёт число процессов: для *параллельного*
сравнения укажите минимум 2 и подходящее доступное количество CPU.
Если островов больше, чем процессов, задачи обслуживаются партиями.

В этом сравнении используется **фиксированное** число поколений,
без ранней остановки по плато. Иначе нельзя гарантировать
одинаковый бюджет итераций. Влияние plateau_limit и plateau_diff
было исследовано отдельно в прежнем эксперименте и не считается
подобранным заново для n=100–2000.

Сохранён лучший *когда-либо просмотренный* вариант, в том числе
если мутант был потерян при отборе. Количество фактических
оценок приспособленности может отличаться из-за миграции; равенство
общего числа особей и поколений не означает равных вычислительных
затрат. Поэтому сравниваются и ошибка, и время.

## Команды

Для быстрой проверки работоспособности (только **игрушечные** матрицы):

    python -m pip install -r requirements.txt
    python -m unittest discover -s tests -v
    python lab1/scale_benchmark.py --mode smoke --workers 2

Полное исследование с реальными размерностями:

    python -u lab1/scale_benchmark.py --mode full --workers 4 --repeats 2 --output-dir results/scale_benchmark_full

Внимание: полный запуск требует значительных CPU и памяти и может
занимать долго. Скрипт сохраняет результаты каждого законченного
класса, но ещё не исследованный класс нельзя считать завершённым.
Перед защитой используйте **только фактически сформированные**
results/scale_benchmark_full, а не результаты smoke.

## Формат результатов

- best_parameters.json — отдельно лучшие проверенные настройки
  одного ГА и островного для каждого класса;
- tuning.csv — все значения гиперпараметров, проверенные при подборе;
- comparison.csv — отдельные прогоны на контрольных матрицах;
- summary.csv — среднее отклонение, доля точных решений, время,
  количество наблюдений;
- plots/ — отдельные графики относительного отклонения и времени
  для малой, средней и большой размерности.

Ошибка = (стоимость_ГА − точная_стоимость) / точная_стоимость.
Ошибка 150% означает решение, которое в 2,5 раза дороже точного.
SciPy используется только для вычисления эталона и **не входит**
в замер времени ГА, в отличие от старой версии эксперимента.
