# Исходные данные и тестирование для презентации

1. До запуска перечислить параметры из DEMO_PARAMETERS.json.
2. Показать actual_holdout_matrix_25.csv: это настоящая матрица финального контроля, а не новый обучающий пример.
3. Показать initial_population_fitness.csv: допустимые перестановки, стоимость, приспособленность каждой особи; среднее совпадает с функцией приспособленности популяции.
4. Показать инверсию до/после из demo_results.json и сохранение допустимости.
5. Показать diagonal_ones_5.csv: на диагонали 1, вне диагонали 100; оптимальная стоимость известна заранее и равна 5. Оба варианта её нашли. Это демонстрационный функциональный тест.
6. Для исследовательских результатов использовать финальную серию 7838 запусков; демонстрационные проверки не прибавляются к её числу.

Точный оптимум реальной матрицы: 185; ГА: 185; средняя приспособленность начальной демонстрационной популяции: 0.000852432990962.
